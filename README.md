# skills

Agent skills I use in Cursor. Each folder is a self-contained skill with its own `SKILL.md` and `README.md`.

| Skill | What it does |
| --- | --- |
| [hairmaxxing](hairmaxxing) | Preview men's haircuts on your own photos, refine them with the agent, and take final images to your barber. |

## Install

Install one skill:

```bash
npx skills add dogukanteber/skills --skill hairmaxxing
```

Or copy a skill's folder into `~/.cursor/skills/` (global) or `.cursor/skills/` in a project.
